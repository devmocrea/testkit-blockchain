Find the largest input a contract function handles before it fails

Usage: soroban-testkit limits [OPTIONS] --contract <PATH> --fn <NAME> --ramp <PARAM>

Options:
      --contract <PATH>            Path to the compiled contract .wasm file
                                   (e.g. `target/wasm32v1-none/release/<crate>.wasm`)
      --no-color                   Never emit ANSI color codes, here or from tools this command runs
                                   (e.g. cargo). Same as setting the `NO_COLOR` environment variable
      --fn <NAME>                  The contract function to ramp, as named in the contract's spec
  -q, --quiet                      Print only results and errors; suppress advisory notes. Cannot be
                                   combined with --verbose
      --ramp <PARAM>               The parameter of --fn to increase on each attempt: an integer type
                                   (ramped as the value) or `Vec<T>` (ramped as its length)
  -v, --verbose                    Print extra diagnostics (commands run, files scanned) to stderr
      --start <N>                  First ramp value to probe (default 0), within the ramp parameter's type range [default: 0]
      --step <N>                   Step between ramp values (default 1; negative probes downwards). Probes are start + k*step for k = 0, 1, 2, 4, ... [default: 1]
      --jobs <N>                   Probe up to N ramp values at once (1 to 8, default 1) [default: 1]
      --probe-timeout <SECONDS>    Stop an individual probe after N seconds (default 120; minimum 1) [default: 120]
      --repeat <N>                 Measure the final value N times (1 to 16, default 1). With N above 1, the report gives the median with the min and max [default: 1]
      --dry-run                    Generate and print one probe's arguments without invoking the contract. This validates the contract spec and is useful when diagnosing defaults
      --bool-default <PARAM=BOOL>  Override a non-ramp bool parameter's default (repeatable): --bool-default enabled=true
      --auth-mode <AUTH_MODE>      Authorization mock scope: all (default), root-only, or none [default: all] [possible values: all, root-only, none]
      --json                       Print the result as a JSON document (`schema_version` 1) on stdout
  -h, --help                       Print help (see more with '--help')

EXAMPLES:
    soroban-testkit limits --contract target/wasm32v1-none/release/my_contract.wasm --fn batch_payout --ramp recipients
    soroban-testkit limits --contract my_contract.wasm --fn transfer --ramp amount
    soroban-testkit limits --contract my_contract.wasm --fn transfer --ramp amount --bool-default paused=true --repeat 5
